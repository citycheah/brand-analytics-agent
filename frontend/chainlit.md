# 📊 Brand Analytics AI Assistant

Welcome to the **Brand Analytics AI Assistant**, a production-grade conversational AI agent designed to analyze competitive advertising intelligence, verify creative assets, and build comprehensive market insights reports.

### Key Capabilities:
1. **Share of Spend & Voice Analysis**: Query the BigQuery database to calculate Share of Spend (SoS) and Share of Voice (SoV) metrics across multiple countries and brands.
2. **Feasibility Validation**: Cross-reference market metrics against predefined spend and impression thresholds to determine candidate feasibility.
3. **Multimodal Creative Verification**: Stream, verify, and validate advertising creatives (images and videos) directly using Gemini's visual reasoning.
4. **Sandboxed Python Sandbox**: Run custom data manipulation, charting, and modeling scripts locally in a secure, isolated Python environment.
5. **Interactive Report Exporting**: Generate and export beautifully styled, self-contained HTML analysis reports stored securely in Cloud Storage.

---

### Quick Start Prompts:
* *"Compare BMW and Mercedes in Germany for Q1 2026, run a feasibility check, and generate an export report."*
* *"Perform a competitive brand analysis for BMW in Singapore for 2026-01-01 to 2026-03-31."*
* *"Analyze the creatives for BMW in Germany and verify if they match official brand identities."*
